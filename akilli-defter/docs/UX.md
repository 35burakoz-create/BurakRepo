# UX Foundations (MVP)

## Visual Language
- Material 3 components, rounded cards, soft shadows.
- Dashboard-first IA with quick actions and recent activity.
- Micro-interactions: animated tab switch, button feedback, smooth state transitions.

## Primary Screens
1. **Auth Screen**
   - Welcome copy
   - Email/password fields
   - Demo sign-in helper
2. **Dashboard Screen**
   - Workspace switcher (Personal / Business)
   - Quick action chips
   - Recent transactions card
   - AI insight placeholder card
3. **Settings Screen**
   - Language segmented control (TR/EN)
   - Dark mode toggle
   - Privacy explanation

## Accessibility
- Minimum tap targets >= 48dp
- Dynamic text compatible layout
- Contrast-safe palettes in dark mode
